# 超分工坊（SuperResApp）

超分工坊是一款基于 Apple Core ML 的 iOS AI 影像增强应用，提供照片超分辨率、视频超分辨率、AI 视频补帧和模型管理功能。用户可以按需选择处理方式与模型，将处理结果预览并保存到系统相册。

## 功能介绍

### 照片超分辨率

- 从系统相册选择照片进行 AI 超分辨率增强。
- 支持选择不同的超分模型，在处理效果与模型特点之间进行选择。
- 展示处理结果，方便检查增强效果。
- 将处理后的图片保存到系统相册。

### 视频处理

视频处理页面提供两种独立模式，可根据需求切换：

**视频超分**
- 使用 AI 超分模型提升视频画面分辨率与细节表现。
- 可选择已安装的视频超分模型。
- 显示处理进度，支持取消处理。
- 处理完成后可预览结果，并保存到系统相册。

**AI 视频补帧**
- 使用 RIFE Lite 对连续视频帧进行运动补偿与中间帧生成。
- 提供 2 倍和 4 倍补帧倍率选择。
- 补帧过程独立于视频超分处理流程。
- 保留视频音轨并输出处理后的视频文件。
- 显示处理进度，支持取消、结果预览和保存到系统相册。

### 模型管理

- 集中查看应用支持的 AI 模型及其下载状态。
- 内置模型可直接用于相应功能。
- 按需下载其他模型，减少首次安装时的应用体积。
- 下载过程提供进度反馈，并对下载文件进行 SHA-256 完整性校验。
- 支持模型文件解压、安装与加载；已下载模型可在模型管理页面进行管理。

## 模型一览

模型是否可用于某项功能，以应用内模型列表及功能页面显示为准。

| 模型 | 主要用途 | 获取方式 |
|---|---|---|
| PiperSR 2x | 实时影像增强及模型加载回退 | 内置 |
| Real-ESRGAN x4v3 | 轻量照片超分 | 内置 |
| Real-ESRGAN x4 | 通用照片超分 | 按需下载 |
| Real-ESRGAN x4plus | 高画质照片超分 | 按需下载 |
| Real-ESRGAN UltraSharp | 锐化增强型照片超分 | 按需下载 |
| SinSR | 扩散式图像增强 | 按需下载 |
| RIFE Lite | AI 视频补帧 | 按需下载 |

## 使用说明

1. 打开对应功能页面，从系统相册选择照片或视频。
2. 照片超分或视频超分可按页面提示选择模型；视频补帧可选择 2 倍或 4 倍倍率。
3. 点击开始处理，等待进度完成。处理期间可按需取消。
4. 在预览页面检查处理结果。
5. 使用保存功能将结果写入系统相册。

首次使用按需下载的模型时，请先在模型管理页面完成下载和安装。模型体积、处理速度及设备性能会影响下载和处理所需时间。

## 隐私与文件处理

- 照片和视频由用户主动从系统相册选择。
- 处理结果可在应用内预览，并由用户决定是否保存到系统相册。
- 模型文件与用户选择的媒体文件用途不同：模型用于本地 AI 推理，媒体文件用于对应的影像处理任务。

## 代码规范与 CI

仓库使用 [SwiftLint](https://realm.github.io/SwiftLint/) 做静态规范检查，配置在 `.swiftlint.yml`。

### 本地运行

```bash
bash scripts/lint.sh            # 只检查
bash scripts/lint.sh --fix      # 自动修复可修复项
bash scripts/lint.sh --strict   # warning 也视为失败（提交前自测用）
```

未安装 SwiftLint 时脚本会自动退回官方 Docker 镜像；macOS 上也可直接 `brew install swiftlint`。

### CI 流水线

`.github/workflows/lint.yml` 在 `push` / `pull_request` 到 `main`、`master` 时触发，包含两个作业：

| 作业 | 运行环境 | 内容 |
|---|---|---|
| `SwiftLint` | `macos-14` | 按 `.swiftlint.yml` 检查，结果以行内注释贴到 PR 变更行，并写入运行摘要 |
| `仓库守卫` | `ubuntu-latest` | 合并冲突标记、CRLF 换行、超过 5MB 的文件 |

`SwiftLint` 作业只在出现 **error** 级问题时失败；warning 会展示但不阻断。需要临时收紧时，可在 Actions 页面手动触发并勾选 `strict`。

### 存量问题的处理

当前代码库已清理行尾空白，配置阈值也按现有规模标定。若后续规则收紧后出现大量历史告警，可生成基线文件把存量冻结，只对新增代码生效：

```bash
swiftlint lint --write-baseline .swiftlint-baseline.json
```

提交该文件后，CI 与本地脚本都会自动带上 `--baseline`。基线应逐步缩小，不要长期依赖。
